1 · The Locked Spec (what we are building)

Cognitive job: Provide persistent, token-budgeted memory for DeepSeek Harness agents by implementing a Cordis MemoryService provider that retrieves relevant memories before inference and asynchronously evaluates new memories after each turn — without modifying DSH core or Remex internals.

Inputs: DSH user/assistant messages, session events, tenant/user config (UUID headers), Remex HTTP API  →  Outputs: Injected <remex_memory> context blocks, async evaluate jobs, optional memory_search tool results

Autonomy level: Supervised plugin — automatic retrieve/inject + async write; no autonomous deletion without explicit tool/phase-2  |  Human-in-the-loop points: Cordis patch install, tenant/user UUID config, cross-session recall acceptance test, L4 VERIFY approval per milestone

Failure tolerance: Read path fail-open (empty context, agent continues); write path best-effort async (log 429/5xx, never block reply); Remex degraded flag honored  |  Trust boundary: HTTP between DSH plugin and Remex CMIS; X-Tenant-ID / X-User-ID enforce isolation; untrusted user content in memory blocks — no prompt injection into Remex judge from plugin

G0 diagnostic — scope: new sibling package · AI: yes (agent loop + memory injection) · distributed: yes (DSH process ↔ Remex service) · trust: yes (tenant headers, external HTTP) · phase: 0→1 (cognitive + architecture, pre-MVP code).
